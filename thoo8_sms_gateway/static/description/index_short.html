Thoo8 SMS Gateway

بوابة الرسائل النصية Thoo8

Module Summary

ملخص المودول

Thoo8 SMS Gateway allows sending SMS messages through multiple providers with dynamic fields, templates, and logging for Odoo 15.

بوابة الرسائل النصية Thoo8 تتيح إرسال الرسائل النصية عبر مزودين متعددين مع دعم الحقول الديناميكية، القوالب، وتسجيل الرسائل في سجل النظام في أودو 15.

Features

الميزات

  • Manage multiple SMS providers with dynamic API fields. إدارة مزودي الرسائل المتعددين مع حقول API ديناميكية.
  • Set default SMS provider and configure auto-send options. تعيين المزود الافتراضي للرسائل وضبط خيارات الإرسال التلقائي.
  • Send SMS using JSON payload with extra parameters. إرسال الرسائل النصية باستخدام JSON مع دعم المتغيرات الإضافية.
  • Success code verification to ensure delivery. التحقق من كود النجاح لضمان التسليم.
  • Log all SMS messages with status, code, and response. تسجيل جميع الرسائل النصية مع الحالة والكود والرد.
  • SMS templates with Jinja2 for dynamic content. قوالب رسائل نصية باستخدام Jinja2 لمحتوى ديناميكي.
  • Insert fields directly from linked models into templates. إدراج حقول مباشرة من الموديلات المرتبطة في القوالب.
  • Test SMS sending with response and delivery status. إرسال رسالة اختبارية مع عرض الرد وحالة التسليم.
